# Stay

**Stay faithful. Stay focused. Stay accountable.**

Stay is a mobile-first accountability platform for practices, limits and blocks: prayer, Scripture, study, focus, digital discipline, recovery and other user-chosen commitments.

## Current build

The repository contains the working mobile product foundation: onboarding, Today dashboard, commitment creation/detail/check-ins, accountability partners/invitations, activity, rule evaluation, privacy/share contracts, Supabase schema/RLS, and the platform-native enforcement boundary.

## Stack

Expo / React Native / TypeScript / Expo Router, with Supabase as the production backend target.

## Run

```bash
cp .env.example .env
npm install
npx expo start
```

See `docs/PRODUCT.md`, `docs/ENFORCEMENT.md`, `docs/BUILD.md`, and `docs/ROADMAP.md`.
