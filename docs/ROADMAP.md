# Stay MVP roadmap

## Implemented foundation
- Mobile navigation and visual system
- Today dashboard
- Commitment model: Practice / Limit / Block
- Gentle / Firm / Strong protection levels
- Commitment creation and check-in flow
- Partner list and invitation flow
- Activity timeline
- Rule evaluator and enforcement-provider contract
- Supabase schema and initial RLS
- Accountability notification/privacy contracts

## Backend integration
- Supabase Auth screens and session restoration
- Replace local store with repository backed by Supabase
- Invitation deep links and acceptance
- Push tokens and server-side notification dispatch
- Scheduled missed-commitment evaluation
- Partner approval workflow for Strong overrides

## Native protection
- Android usage-access provider
- Android local VPN/DNS category provider
- Android protection-health/tamper signals
- iOS FamilyControls/DeviceActivity/ManagedSettings provider
- Native settings/permission diagnostics

## Product expansion
- Prayer timer and Bible-plan integrations
- Focus sessions
- Recovery/reflection flow after a support moment
- Weekly accountability reports
- Pattern insights
- Groups / mentors
- Optional faith-specific experience packs without making the core product unusable for general accountability
